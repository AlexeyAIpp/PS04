# 📚 Проводник по Википедии

Программа на Python для поиска и чтения статей русскоязычной Википедии.

Введите интересующую тему — программа откроет страницу в Firefox. Читайте статью по абзацам прямо в терминале или переходите к другим статьям по ссылкам из текста.

---

## ✨ Возможности

- 🔎 Поиск статьи по вашему запросу.
- 📖 Чтение текста по одному абзацу.
- 🔗 Переход к связанным статьям.
- 🚪 Выход с закрытием браузера.

## 🎮 Управление

После запуска введите тему для поиска:

```text
Что найти в Википедии? Трансформатор
```

### Главное меню

| Команда | Действие |
|:-------:|----------|
| `1` | Читать абзацы статьи |
| `2` | Показать ссылки из текста |
| `3` | Завершить программу и закрыть браузер |

### 📖 Чтение статьи

Выберите пункт `1`, чтобы читать статью по абзацам.

| Команда | Действие |
|:-------:|----------|
| `Enter` | Следующий абзац |
| `0` + `Enter` | Вернуться в меню |

### 🔗 Переход к другой статье

Выберите пункт `2`, чтобы увидеть пронумерованный список ссылок.

- Введите **номер статьи** и нажмите `Enter`, чтобы открыть её.
- Введите `0` и нажмите `Enter`, чтобы вернуться в меню.

После перехода можно продолжить чтение или выбрать следующую статью.

---

> 💡 Все команды вводятся в терминале. Страницы открываются в браузере Firefox.
